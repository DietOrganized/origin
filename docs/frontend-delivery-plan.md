# 前端分阶段交付

目标仓库：https://github.com/DietOrganized/origin

这是对已完成工作的分阶段整理，不更改实际开发日期。

## 第一阶段：页面结构与视觉设计

本次范围：六个独立 JSP、公共头尾布局、页面路由、统一样式、响应式布局。页面显示预览占位数据，按钮明确提示后续对接状态，不调用业务 API。

入口：应用根路径，或 /jsp/overview。其余模块：/jsp/meals、/jsp/stats、/jsp/recipes、/jsp/advice、/jsp/profile。沿用仓库现有 Spring MVC JSP 解析配置。

## 第二阶段：接口与业务交互（待上传）

登录注册、饮食录入及明细编辑、历史记录、统计图表、个人目标、菜谱与建议接口对接，包含连接状态和注册错误提示修复。

## 第三阶段：AI 体验完善（待上传）

历史饮食建议折叠并标注生成时间；食材与做法左右布局；生成成功直接展示菜谱；相关回归验证。

## 提交边界

不包含 application-secret.yml、数据库凭据、API Key、target/、.idea/ 或本机运行数据。第二、三阶段由后续请求分别提交。
